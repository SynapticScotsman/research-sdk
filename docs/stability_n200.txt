turn deg  = angle between the direction the old plan pointed and the
            direction the replacement points, from where the robot is.
            0 means the replan did not change the next move.
reversals = share of replans turning more than 90 degrees, so the new
            plan sends the robot back the way it came.
rev/run   = reversals per run. This is the one that tracks arrival:
            the rate alone does not, because a planner that reverses
            half the time but replans three times per run reverses
            once or twice in total and still gets there.
shift mm  = mean distance between the old route and the new one over
            their whole length. 0 means the route did not move.
Both read 0 for a robot that never changes its mind.
